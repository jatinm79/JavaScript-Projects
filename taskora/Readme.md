# Taskora

**Taskora** is a minimalist task management web application built using **Vanilla JavaScript**, **HTML5**, and **CSS3**. It provides a fast and responsive interface for managing to-do tasks efficiently without relying on external libraries or frameworks. Taskora is designed to showcase fundamental front-end development skills including DOM manipulation, event handling, state management, and persistent data storage using native browser APIs.

<br/>

##  Features

-  **Add Tasks** – Users can dynamically add new tasks through a clean input interface.
-  **Delete Tasks** – Remove individual tasks from the list with immediate visual feedback.
-  **Mark as Completed** – Toggle task completion status with CSS-based visual indication.
-  **Persistent Storage** – Uses `localStorage` to retain tasks across browser sessions.
-  **Responsive Design** – Mobile-first layout ensures compatibility across devices.
-  **Minimalist UI** – Clean and distraction-free design focused on productivity.

<br/>

##  Tech Stack

| Technology      | Purpose                                 |
|------------------|-----------------------------------------|
| **HTML5**        | Page structure and semantic layout      |
| **CSS3**         | Styling, layout design, responsiveness  |
| **JavaScript (ES6+)** | App logic, state management, and interaction handling |

<br/>

## Conclusion

Taskora demonstrates how to develop a fully functional, responsive task management system using core web technologies. The project emphasizes simplicity, modularity, and best practices in front-end development. It serves as a solid foundation for learners and professionals aiming to build scalable JavaScript applications without relying on frameworks.
